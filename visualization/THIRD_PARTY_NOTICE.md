# Visualization source notice

The files in this directory were collected from the visualization pipeline in [AIGeeksGroup/ReMoMask](https://github.com/AIGeeksGroup/ReMoMask), commit `630eda1f825bcc2ffb613a7270e1f5b6ac8baea2`, which itself builds on earlier open-source motion visualization and SMPL fitting code.

The vendored copy contains only the joint-to-SMPL fitting and Blender rendering path used by this repository. Local path handling and a small number of portability issues were corrected for this release.

SMPL, SMPL-X, and their model or prior data are not included. Users must obtain those assets separately and follow their respective licenses. Some source files retain additional upstream copyright and license notices.
