# Required SMPL assets

Download these files from their authorized sources and place them in this directory:

- `SMPL_NEUTRAL.pkl`
- `neutral_smpl_mean_params.h5`
- `gmm_08.pkl`

The fitting script creates `smplh.faces` from `SMPL_NEUTRAL.pkl` for the Blender renderer. These assets are not covered by the SafeMo or ReMoMask source-code permission.
